# Card Case

A static browser card-combat game, with a new single-fight experiment.

## Play

Open `index.html`, or run `python -m http.server 8000` and visit `http://localhost:8000`.
Select **炉心决斗** to play the standalone Boss-fight prototype. The original eleven-room game remains available from the homepage.

## 炉心决斗

Draw four cards each round and spend 3 AP on cards or movement. Read the Boss's lane warnings, dodge attacks, and interrupt its every-third-round charge by dealing 14 damage. Lose or win, then restart for another run.

No build step or runtime service is required. The game is published at [couldes.github.io/card-case](https://couldes.github.io/card-case/).
